## AI와 일하는 방식

AI에게 "만들어 줘"라고만 하면 그럴듯하지만 틀린 결과가 나올 때가 있어서, 건축 현장처럼 역할을 나눕니다.

1. **계획 (설계도)**: 무엇이 되면 끝인지 완료 조건부터 정합니다
2. **구현 (시공)**: 계획서를 보고 AI가 만듭니다
3. **검증 (감리)**: 다른 AI가 직접 실행해서 판정합니다. 검사하는 AI는 코드를 못 고치게 해서, 만든 쪽이 스스로 통과시키지 못하게 했습니다

위 프로젝트들도 이 방식으로 점검했습니다. 점검 AI 7개를 동시에 돌려 기능 250개를 확인했고, 28개 실패를 찾아 고친 뒤 데모로 공개했습니다.
